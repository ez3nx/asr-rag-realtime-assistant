## ASR-RAG-Realtime-Assistant

Комплексное решение на базе ASR и RAG‑пайплайна для генерации подсказок оператору в режиме реального времени на основе вопросов от абонента.

### Цели проекта

- Сокращение времени обработки обращения
- Повышение качества ответов оператора за счет доступа к актуальным знаниям и сценариям
- Снижение нагрузки на обучение операторов за счет автоматизированных подсказок

### Описание

Система в реальном времени обрабатывает аудиопоток разговора оператора и абонента:

1. Распознавание речи (ASR, STT)
2. Intent-classification - определение триггерного события для запуска RAG pipeline
3. Извлечение контекста и формулировка запроса к базе знаний (RAG)
4. Генерация релевантных подсказок оператору

Подсказки отображаются в интерфейсе оператора и помогают ему формулировать ответы, уточняющие вопросы и следующие шаги.

### Основные компоненты (план)

- **ASR‑модуль**: онлайн‑распознавание речи абонента и оператора.
- **RAG‑пайплайн**:
  - подготовка и индексация базы знаний (документация, скрипты, FAQ);
  - поиск релевантных документов по запросу;
  - генерация ответа/подсказки на основе найденного контента.
- **Сервис рекомендаций оператору**:
  - преобразование результатов RAG в структурированные подсказки;
  - приоритизация и обновление подсказок по мере развития диалога.
- **Интеграционный слой**:
  - интеграция с интерфейсом оператора.
